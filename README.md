# Каскадные банкротства

Учебный симулятор для исследования того, как структура финансовой сети влияет на распространение банкротств.

## Логика модели

- Сеть из 30–100 банков: `L[i, j]` — долг банка `j` перед банком `i`, `K[i]` — начальный капитал.
- Внешний шок `x[i]` уменьшает капитал выбранного банка.
- Банк с отрицательным капиталом банкротится; его кредиторы полностью теряют требования к нему.
- На каждом шаге капитал пересчитывается от начального значения:

  `K_remaining[i] = K[i] - x[i] - sum(L[i, j] for j in bankrupt)`

- Новые банкротства добавляются одновременно. Расчёт заканчивается, когда их больше нет; каждая потеря учитывается один раз.

## План реализации

1. Построить три типа сетей: равномерную, с крупными центрами и с тесно связанными группами.
2. Реализовать матрицу долгов и пошаговый алгоритм каскада.
3. Добавить интерфейс с выбором сети, капитала, банка и размера шока; визуализировать распространение банкротств.
4. Провести повторные эксперименты при одинаковых числе банков, общем объёме долгов и капитале каждого банка; учитывать различия индивидуальных долговых позиций.
5. Сравнить итоговую долю банкротов и число волн каскада, построить графики.

**Результат:** интерактивный симулятор и сравнение устойчивости трёх структур сети.
